## Contribution tax disclosure

The service operates a 20:1 contribution model for trial-pool accounts. For every 20 successful applications made on a user's behalf using the shared trial LLM pool, one application is submitted on the maintainer's (Sijoy) behalf using the same pool. Users who attach their own provider keys (BYOK) are exempt from this contribution. Users may opt out of trial-pool usage at any time in Settings; opting out disables the shared pool and disables contributions.
